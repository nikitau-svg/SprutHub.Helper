# Поддержка

SprutHub.Helper развивается как бесплатный некоммерческий проект без гарантированного SLA. Точный отчёт помогает отличить ошибку приложения от ограничения Android, оболочки телефона или изменения внутреннего API SprutHub.

## Перед созданием Issue

1. Проверьте, что используется актуальная beta из [GitHub Releases](https://github.com/nikitau-svg/SprutHub.Helper/releases).
2. Найдите ситуацию в [FAQ](docs/FAQ.md) и [матрице возможностей](docs/CAPABILITIES.md).
3. Повторите проблему и подготовьте [безопасный диагностический отчёт](docs/DIAGNOSTICS.md).
4. Используйте шаблон **Сообщить об ошибке** в GitHub Issues.

Не публикуйте пароль, e-mail, endpoint, hub ID/серийник, IP, координаты, данные здоровья, полный DevInfo или signing-файлы. Снимок экрана нужно обрезать или замазать до загрузки.

Запрос новой функции создавайте отдельным Issue и описывайте пользовательский сценарий, а не только желаемую кнопку. Совместимость конкретной оболочки полезно сопровождать моделью телефона и версией Android.

Для уязвимостей используйте [SECURITY.md](SECURITY.md); публичный Issue с секретом или рабочим exploit создавать нельзя.
