# Установка и обновление APK

## Где брать приложение

Используйте только APK из [GitHub Releases](https://github.com/nikitau-svg/SprutHub.Helper/releases). Для каждой beta публикуются два файла:

- `SprutHub.Helper-X.Y.Z-beta.N.apk` — устанавливаемое приложение;
- файл с окончанием `.apk.sha256` — контрольная сумма именно этого APK.

APK в официальном Telegram-анонсе формируется из того же проверенного GitHub Release. Файл из случайного сообщения, зеркала или переименованного архива устанавливать не следует.

## Если вместо установки снова открывается GitHub

В таком случае браузер обычно сохранил **веб-страницу релиза**, а не APK. В Samsung «Скачанные файлы» такой объект отмечен значком глобуса и относится к категории страниц.

1. Удалите ошибочно сохранённую страницу.
2. Откройте раздел **Assets** нужного Release.
3. Нажмите именно на имя файла, которое заканчивается на `.apk`, а не на заголовок Release.
4. После загрузки откройте **Мои файлы → Загрузки**. У правильного файла расширение `.apk` и обычный значок файла/приложения, а не глобус.

Если мобильный GitHub прячет Assets, разверните их стрелкой либо используйте прямую ссылку на APK из README или Telegram-анонса.

## Первая установка

1. Нажмите на скачанный `.apk` в системном файловом менеджере.
2. Если Android заблокировал установку, разрешите **Установку неизвестных приложений** только тому браузеру или файловому менеджеру, из которого открыт APK.
3. Вернитесь назад и подтвердите установку SprutHub Helper.
4. После установки это разрешение источнику можно снова выключить.

Android или Play Protect могут отдельно предупредить о приложении не из Google Play. Проверьте имя файла, источник и SHA-256; при любом несовпадении отмените установку.

## Обновление без потери настроек

Скачайте более новую beta и установите её поверх существующей. Не удаляйте приложение: удаление очищает локальные пароли, назначения плиток/панелей, привязки виртуальных устройств и геозоны.

Все официальные beta подписаны одним постоянным сертификатом. Поэтому Android должен предложить **Обновить**, а не отдельную установку. Ошибка `Приложение не установлено` обычно означает одну из причин:

- APK повреждён или скачан не полностью;
- файл подписан другим ключом, например это сторонняя/debug-сборка;
- устанавливается более старый `versionCode` поверх нового;
- на телефоне недостаточно места или установка запрещена политикой устройства.

Не обходите несовпадение подписи удалением рабочей установки. Сначала заново скачайте APK из GitHub Release и сравните контрольную сумму.

## Проверка SHA-256

Контрольная сумма в `.apk.sha256` должна полностью совпасть с вычисленной для APK. На компьютере:

```bash
# macOS
shasum -a 256 SprutHub.Helper-X.Y.Z-beta.N.apk

# Linux
sha256sum SprutHub.Helper-X.Y.Z-beta.N.apk
```

На Android используйте системный или доверенный файловый инструмент, умеющий показывать SHA-256. Не передавайте APK случайному онлайн-сервису для проверки.

## После обновления

Откройте Helper один раз и убедитесь, что главный экран показывает `Всё работает` либо одно понятное действие. Проверьте назначенный виджет, плитку и крупную панель. Полная матрица обновления и восстановления находится в [dead-case тестах](DEAD_CASE_TESTING.md).
