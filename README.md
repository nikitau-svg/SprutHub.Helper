# SprutHub Helper

Небольшое Android-приложение для системного управления SprutHub без дублирования его веб-интерфейса.

## Что умеет

- подключается к SprutHub напрямую по WebSocket/JSON-RPC;
- в режиме «Авто» сначала использует локальный хаб, затем защищённое облачное подключение;
- показывает устройства в системной панели Android Device Controls (включая экран блокировки на поддерживаемых Samsung);
- даёт 12 назначаемых плиток быстрых настроек;
- сохраняет каталог для быстрого запуска и принимает обновления состояний через WebSocket;
- по явной команде создаёт в SprutHub виртуальный аксессуар «Здоровье» и публикует в него выбранные данные Health Connect;
- добавляет к аксессуару заряд, состояние зарядки, модель телефона, версию Android и время последней синхронизации;
- обновляет здоровье вручную и в фоне через WorkManager примерно раз в 15 минут;
- хранит пароль в Android Keystore и исключает настройки из резервных копий.

По умолчанию проект настроен для хаба `68C341B253468E4B` по адресу `192.168.1.135`. E-mail и пароль вводятся только на телефоне.

## Установка и настройка

1. Установите APK и откройте **SprutHub Helper**.
2. Введите учётные данные SprutHub, сохраните настройки и нажмите **Проверить и загрузить устройства**.
3. Нажмите **В панель** у нужного устройства, чтобы Android предложил добавить его в системное управление.
4. Нажмите **Плитка**, выберите слот и подтвердите добавление в шторку. На Android 11–12 плитка добавляется через обычное редактирование шторки.

## Здоровье и телефон

1. В карточке **Здоровье** отметьте нужные показатели и выберите комнату SprutHub.
2. Выдайте приложению выбранные разрешения Health Connect.
3. Нажмите **Создать устройство в SprutHub**. До этого приложение ничего в хабе не создаёт.
4. Включите фоновое обновление и разрешите приложению неограниченную работу батареи в настройках Samsung.

Поддерживаются шаги, пульс, пульс в покое, последний сон, вес, SpO₂, давление, активные калории, дистанция, температура, дыхание и HRV. Для каждого поля создаётся отдельный универсальный сервис `C_Option`; приложение получает реальные идентификаторы созданных характеристик и сохраняет их для последующих обновлений.

Данные здоровья передаются **только напрямую в локальный хаб `192.168.1.135`**. Облачный fallback и Cloudflare для них намеренно отключены. Если телефон не дома, задача завершается без отправки и повторяется позднее. Android может сдвигать 15-минутный интервал для экономии батареи; после принудительной остановки приложения фоновые задачи не возобновятся до следующего ручного запуска.

## Архитектура

Приложение не требует REST-моста, Node-RED, отдельного сервера или Cloudflare. Локальное `ws://` соединение разрешено политикой Android только для `192.168.1.135`; облачное соединение работает через `wss://beta.spruthub.com/spruthub`.

Виртуальный аксессуар создаётся через тот же внутренний JSON-RPC/WebSocket-протокол, которым пользуется веб-интерфейс SprutHub: приложение запрашивает доступные типы сервисов, выбирает подходящие характеристики `C_Option`, создаёт аксессуар и затем обновляет конкретные `aId/sId/cId`. Это внутренний, а не публично стабилизированный API, поэтому при несовместимом обновлении SprutHub приложение покажет понятную ошибку вместо молчаливой потери данных.

## Сборка

GitHub Actions собирает и тестирует устанавливаемый debug APK при каждом push в `main`. Артефакт называется `SprutHub.Helper-debug-apk`.

SprutHub не публикует стабильный API для этого протокола, поэтому парсер сделан терпимым к дополнительным полям, а ошибки подключения видны в разделе диагностики.
